# Sereno

App personale per la giornata: attività, note e abitudini. I dati restano sul dispositivo (localStorage), senza account.

Sito: https://olly-2014.github.io/Prova-/

`index.html` e `assets/` sono la build per GitHub Pages. Per sviluppare usa `app.html` e `npm run dev`.

## Avvio

```bash
npm install
npm run dev
```

Poi apri `http://localhost:5173`.

## Cosa puoi fare

- **Oggi**: saluto, avanzamento del giorno, lista rapida e check delle abitudini
- **Attività**: aggiungi, completa, filtra ed elimina
- **Note**: taccuino con modifica ed eliminazione
- **Abitudini**: griglia settimanale da lunedì a domenica

## Build

```bash
npm run build
npm run preview
```
